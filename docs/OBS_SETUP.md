# OBS 推流到 Kick：設定步驟（給開播那台電腦的人）

目的：把測試台的「直播畫面頁」（影片 + 小遊 + 字幕 + AI 標示）用 OBS 推到 Kick。留言那一邊已經接好，不用動。

## 0. 準備
- 一台 Windows 或 Mac 電腦，網路穩定（上傳至少 10 Mbps）。
- 下載 OBS Studio：https://obsproject.com/ （免費）。裝好開啟，第一次的「自動設定精靈」可以直接取消。
- 這台電腦**不要**另外開著測試台的控制頁出聲音；要開的話勾「本頁靜音」。

## 1. 加入畫面來源
1. 下方「來源」面板按「＋」→ 選「瀏覽器」→ 新建，名稱隨便（例如 小遊直播畫面）→ 確定。
2. 設定：
   - 網址：測試台右上 Kick 面板那行「OBS 瀏覽器來源網址」（含 `?view=live&key=…`）。
   - 寬 1920、高 1080。
   - 勾選「透過 OBS 控制音訊」。
   - 「來源不可見時關閉來源」不要勾；「場景變成活動狀態時重新整理」不要勾。
3. 確定。等 5 到 10 秒，畫面上應出現遊戲影片、右下角小遊、左下角標示。小遊的 3D 檔第一次要載入約 10 MB。
4. 若畫面只有影片、沒有小遊：OBS 設定 → 進階 → 勾「啟用瀏覽器來源硬體加速」→ 重開 OBS。

## 2. 聲音
- 「音訊混音器」會多一條「小遊直播畫面」，這條就是遊戲音效加小遊的聲音，讓它有在跳就對了。
- 把「桌面音效」和「麥克風」兩條**靜音**（按喇叭圖示），不然會混進電腦其他聲音。
- 想自己在電腦上也聽到：在那條音軌的齒輪 → 進階音訊屬性 → 音訊監聽選「監聽並輸出」。不想聽就維持「監聽關閉」。

## 3. 填 Kick 串流金鑰
1. 另開瀏覽器到 Kick 創作者後台：https://dashboard.kick.com/settings/stream （或 kick.com 右上頭像 → Creator Dashboard → Settings → Stream Key）。
2. 會看到「Stream URL」和「Stream Key」，金鑰按顯示後複製。**金鑰等於你的頻道鑰匙，不要貼到群組。**
3. 回 OBS：設定 → 串流。
   - 服務下拉若有「Kick」就選 Kick，貼上 Stream Key。
   - 沒有的話選「自訂」，伺服器貼 Stream URL，串流金鑰貼 Stream Key。
4. 設定 → 輸出：輸出模式「簡易」，影像位元率 4500 Kbps，編碼器有 NVENC 就選它、沒有選 x264。音訊位元率 160。
5. 設定 → 影像：基礎與輸出解析度都 1920×1080，FPS 30。
6. 套用、確定。

## 4. 開播前在 Kick 後台填資料
- 標題寫明是 AI 主播，例如「AI 主播小遊 陪玩測試」。
- 分類選對應的博弈／Slots & Casino 類別，開啟成人（18+）標示。
- 語言選中文。
- 這些是 Kick 守則要求，不填會被下架或警告。

## 5. 開播
1. OBS 右下按「開始串流」。右下角狀態列變綠、顯示 kb/s 數字就代表在推。
2. 用另一台裝置或手機開 kick.com/vincentchiu 確認：中間有畫面、有聲音、右下角小遊會動。Kick 畫面會比 OBS 慢 5 到 15 秒，正常。
3. 在 Kick 聊天室打一句，看測試台右邊出現 🟢 Kick 留言、小遊回話，Kick 畫面上小遊的嘴有動、字幕有出現。
4. 結束按「停止串流」。

## 常見狀況
- OBS 畫面黑：網址少了 `?view=live&key=…`，或存取碼錯。
- 有畫面沒聲音：瀏覽器來源沒勾「透過 OBS 控制音訊」，或音軌被靜音。
- 聲音出兩次：同一台電腦還開著測試台控制頁沒靜音。
- Kick 顯示離線但 OBS 說在推：金鑰貼錯或貼到別的服務，重新複製一次。
- 小遊不講話：看測試台右邊，若出現「已停止付費呼叫」，先處理 AI Token King 的額度，再按「重新啟用付費呼叫」。
